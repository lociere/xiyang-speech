# 交付验收

## 交付内容

- 项目代码提交及固定的子模块版本。
- Conda 环境定义、pip 依赖清单和本机配置模板。
- 模型及辅助资源清单、获取方式和使用许可。
- 授权参考录音、安装及运行说明。
- 目标设备的硬件、驱动、依赖版本和验收结果。

## 环境与运行

- [ ] 在目标设备按 [安装说明](setup.md) 完成干净安装。
- [ ] 四个环境的 pip check 通过。
- [ ] 主模型、WeText 和 S3FD 的文件校验通过。
- [ ] pytest、Ruff 和 Git 差异检查通过。
- [ ] 统一启动后 /ready 返回 200，模型处于待命状态。
- [ ] 连续任务复用模型，切换前释放旧模型，空闲后自动卸载。
- [ ] 整体停止无残留进程，应用异常退出可恢复。
- [ ] 应用重启后已完成结果可访问，未完成任务明确失败。
- [ ] 离线部署时，在断网目标设备验证全部功能。

## 功能与异常

- [ ] 录音识别、结果展示和复制可用。
- [ ] 方言词、短句、数字及日期合成可播放、下载，并经母语者试听。
- [ ] 正脸照片加录音、照片加文字均可生成、播放和下载视频。
- [ ] 提交期间防止重复点击，排队和模型加载状态可见。
- [ ] 图片说话任务刷新页面后可继续查询。
- [ ] 空输入、格式错误、超限文件、过长录音、无人脸和队列满均有错误反馈。
- [ ] 模型加载或推理失败后，任务明确失败，后续任务可继续处理。
- [ ] 桌面及移动屏幕中的状态、表单和结果可正常访问。

## 容量与数据

- [ ] 按约定的最长输入、图片分辨率和排队量测量内存、显存及耗时。
- [ ] 记录冷启动和连续任务耗时，确认满足使用场景。
- [ ] 明确上传及输出的保留期限、备份和清理方式。
- [ ] 确认录音、图片和模型的使用及分发授权。
