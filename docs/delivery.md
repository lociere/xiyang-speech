# 交付说明

功能完成后更新本页，交付人按同一份说明安装并使用即可。

## 交付内容

- 最终代码版本和仓库地址。
- 安装与运行说明。
- 对应模型、方言参考录音及其转写，或明确的获取方式。
- 本地配置示例；约定好模型目录、输出目录和启动方式。
- 简短使用说明：识别、生成、复制、播放和下载。
- MuseTalk 源码子模块、固定依赖和全部辅助权重，包括 S3FD 缓存文件（见 `musetalk.md`）。

模型和录音单独交付，不放进普通 Git；按对应模型许可和录音授权提供。

## 验收

- [ ] 在目标电脑按安装说明完成环境配置，启动成功。
- [ ] 上传真实昔阳话录音，转写可用，可以复制结果。
- [ ] 输入文字，生成语音，可以播放和下载，人工试听通过。
- [ ] 上传单人正脸图片，分别用文字和已有音频生成视频，可以播放和下载。
- [ ] 人脸检测失败有明确提示；奇数尺寸图片能正常生成视频。
- [ ] 检查常用方言词、数字、日期以及约定的最长输入。
- [ ] 无效文件、空输入或运行失败时能看到明确提示。
