# 昔阳方言语音识别与生成系统

提供两个功能：

- 昔阳方言音频转文字。
- 输入文字生成昔阳方言语音。

## 技术方案

- 前端：单页 Web。
- 后端：FastAPI。
- 语音识别：Fun-ASR-Nano。
- 语音生成：CosyVoice 3。

## 当前阶段

正在进行环境配置与模型推理验证，前后端业务功能尚未开发。

## 目录说明

- `backend/`：后端代码。
- `frontend/`：前端代码。
- `docs/`：配置流程和开发文档。
- `requirements/`：依赖及上游版本记录。
- `patches/`：对上游代码的本地修改。

## 模型与数据

模型权重、参考录音和生成音频保留在本地，不上传本仓库。

Fun-ASR 与 CosyVoice 分别使用独立的 Python 环境。上游来源及代码版本记录在 `requirements/` 中。
